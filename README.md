# Simulação Classroom

Um repositório de páginas de navegação para disciplinas escolares com foco em sala de aula e ensino remoto.

## Sobre

Este projeto contém uma coleção de páginas HTML simples para várias disciplinas, como:

- Matemática II
- Física II
- Programação Orientada a Objetos
- Engenharia de Software
- Filosofia II
- Educação Física II

## Estrutura do projeto

- `index.html` — página inicial que liga para as disciplinas disponíveis
- `Matemática II.html` — página de disciplina de Matemática II
- `Física II.html` — página de disciplina de Física II
- `Programação Orientada à Objetos.html` — página de disciplina de POO
- `Engenharia de Software.html` — página de disciplina de Engenharia de Software
- `Filosofia II.html` — página de disciplina de Filosofia II
- `Educação Física II.html` — página de disciplina de Educação Física II

## Como usar

1. Abra `index.html` em um navegador.
2. Navegue pelas disciplinas clicando nos links.
3. Utilize o projeto como exemplo ou base para criar sua própria plataforma de simulação de sala de aula.

## Personalização

- Adicione novas disciplinas criando novos arquivos `.html`
- Atualize o `index.html` para incluir links aos novos conteúdos
- Ajuste layout e estilo diretamente nos arquivos HTML

## Objetivo

Fornecer um exemplo simples e acessível de site de navegação entre disciplinas, útil para projetos escolares e demonstrações de navegação em HTML.
